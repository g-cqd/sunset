The second alpha of Sunset. Expect rough edges, and settings or saved state that a later build may not read.

**What changed since alpha.1.**
- Smaller: the app is 40 MB (it was 52) and the download 20 MB. AemiSDR, the library under the blurs, no longer ships preview photos nothing used, and the app keeps only the shaders a Mac runs.
- Builds with the macOS 26.5 SDK as well as the 27 one: the web pages' hardened mode is used from macOS 26.5, and Global Privacy Control is turned on where WebKit offers it.
- Under the hood: the tests wait for what happens instead of for time (Aemi's AemiTestKit), and CI runs three analyzers (unused code, clones, retain cycles).

**Install.** Unzip, move Sunset.app to Applications, open it. It is signed with a Developer ID and notarised by Apple, so it opens without a warning. It needs macOS 26 or later and a Mac with Apple silicon.

**Check the download.** `shasum -a 256 -c Sunset-v0.1.0-alpha.2-macos-arm64.zip.sha256` in the folder holding both files.

**Not in it yet.** Linux; Intel Macs; updates (download the next build by hand); several pieces of the roadmap (`docs/roadmap`, each entry says what is not done).

Report what breaks in the repository's issues.
