The twentieth alpha of Sunset: an update card in the sidebar; the configuration file's keys follow Settings' sections;
Move Tab to Space; following a terminal's output from the `sunset` tool; tabs dragged out of a window open in a new one;
and fixes for Settings in a narrow pane, a split tab's menu, and drag targets. Expect rough edges, and settings or saved
state that a later build may not read.

**What changed since alpha.19.**
- **Updates in the sidebar.** An update found or ready is a card above Now Playing: Download, Restart to Update, What's
  New, Not Now.
- **The file's keys follow Settings' sections.** `terminal.font`, `terminal.colors`, `terminal.cursor`,
  `terminal.scrollback`, `terminal.padding`, `appearance.material`, `appearance.blur`, `documents.sort`,
  `features.passwords`. The former keys are still read; a file that has them is moved once to the new ones, as it was
  written, comments kept, the former file beside it as `config.json.before-keys`.
- **Commands.**
  - **Move Tab to Space…** (Spaces menu, command bar): the bar lists the other Spaces; the one chosen gets the tab,
    running.
  - **Following a terminal's output**: `sunset read --since N` gives the lines from N on and the next N to read from;
    `read_pane` takes `since` in `sunset mcp`.
- **Tabs and windows.**
  - A tab dragged out of every window opens in a new window of its Space, with the tabs selected with it; a pinned tab or
    a Favorite leaves its section for Today, a pane its split. Dropped on the panes with Option held, the same.
  - A pinned tab dragged over the panes splits with the tab shown there.
  - A tab's preview card goes as soon as a drag begins.
  - A split tab's menu says what each item closes: **Close This Pane**, **Separate Panes into N Tabs** (nothing
    closes), **Close Tab and Its N Panes**; a kept split's **Delete and Close Its N Panes**.
  - Where a drag would go in the sidebar is drawn in the text's ink, not the accent.
- **Settings in a narrow pane**: the list of sections becomes a menu over the page.
- **Releases** are made by one script, from a commit, with both variants notarised at once; an update package covers the
  latest release only (an older Sunset downloads the zip).

**Two variants of one app.**
- **Sunset** (`Sunset-v0.1.0-alpha.20-…`): pages on the system's WebKit, the one Safari uses.
- **Sunset with its own WebKit** (`Sunset-WebKit-v0.1.0-alpha.20-…`): the same app with WebKit's main branch at
  `c308255c50` and 37 patches of ours. Switch between them in Settings › General › Updates › Web engine.

**Install.** Unzip, move the app to Applications, open it. Both are signed with a Developer ID and notarised by Apple.
They need macOS 26 or later and a Mac with Apple silicon.

**Check the download.** `shasum -a 256 -c NAME.zip.sha256` in the folder holding both files.

**Not in it yet.** Linux; Intel Macs; two-key shortcut sequences; syncing the vault between Macs; KDBX / 1PUX imports;
protected video on some sites.

Report what breaks in the repository's issues.
