The sixteenth alpha of Sunset: profile-isolation fixes across Spaces, tabs, Favorites, Pinned grids, popups, and extensions;
sealed `.svault` vault backups and automatic quit backups; real streaming update progress; and automated WebKit update checks.
Expect rough edges, and settings or saved state that a later build may not read.

**What changed since alpha.15.**
- **Profile isolation across Spaces, tabs, Favorites, Pinned grids, popups, and extensions.** Fixed 8 cross-profile isolation
  leaks so a web session from one profile can never carry over into a Space of another profile:
  - *Move to Space* and *Join* restart non-private web pages under the destination profile and clear stale Reload-As overrides
    (same-profile moves and private tabs keep running untouched).
  - Cross-window drags check the Space's actual profile rather than Favorites ownership.
  - Deleting a Space into a neighbour of another profile, editing a Space's profile, or removing a profile restarts both open
    tabs and Space-owned open Favorites.
  - App-shared Pinned grid entries (`spaces.pinned = app`) track their opening profile and reload cleanly when opened,
    released, or moved to Favorites in a Space of a different profile.
  - Incoming peek links, standalone-tab New Tab handoffs, and popup-to-Space moves preserve or reload into the destination
    Space's profile.
  - Extensions update their active window profile dynamically when switching Spaces and bind their controller's default data
    store to the profile's `VariantStore`.
- **Sealed `.svault` vault backups, automatic backups, and emergency sheet.** The Passwords section's "…" menu adds
  **Back Up Vault (.svault)…** and **Restore from Backup (.svault)…** (versioned, sealed with the vault key, never carrying
  device-bound Touch ID wraps, owner-only `0600` writes, opens on any Mac with the master password or recovery code).
  **Settings › Privacy & Security › Passwords** adds automatic backup folder and rotation count (`passwords.backupFolder`,
  `passwords.backupKeep`) written at quit. The recovery code view adds **Print Emergency Sheet…** with a scannable QR code.
- **Updates: real streaming download progress and visible failures.** Replaced `RangeDownloadDelegate` with delegate-driven
  `UpdateHTTPTransfer` so byte-range `.deltas` and full `.zip` downloads stream real progress, moved staging/verification off
  the main actor, added animated stage/linear progress indicators in Settings and the update window, and surfaced update
  failures with a **Try Again** action.
- **WebKit maintenance & CI.** Added daily WebKit security advisory + patch dry-run checks in CI and scheduled local WebKit
  update/auto-release scripts (ADR-0127), plus macOS 26.5 SDK CI fixes (`TerminalCommands`).

**Two variants of one app.**
- **Sunset** (`Sunset-v0.1.0-alpha.16-…`): pages on the system's WebKit, the one Safari uses.
- **Sunset with its own WebKit** (`Sunset-WebKit-v0.1.0-alpha.16-…`): the same app with WebKit's main branch at 944f9ff672
  and 37 patches of ours. Switch between them in Settings › General › Updates › Web engine.

**Install.** Unzip, move the app to Applications, open it. Both are signed with a Developer ID and notarised by Apple. They
need macOS 26 or later and a Mac with Apple silicon.

**Check the download.** `shasum -a 256 -c NAME.zip.sha256` in the folder holding both files.

**Known.** Setting up Passwords with Touch ID on can close the window that shows the recovery code a few seconds after it
appears: copy the code at once, or set up without Touch ID. Being fixed.

**Not in it yet.** Linux; Intel Macs; terminal scrollback search; restoring terminal screens across quit; Sixel and iTerm2's
images, kitty's animations; syncing the vault between Macs, KDBX / 1PUX / OTP-app imports; protected video on some sites
(CNN); several pieces of the roadmap (`docs/roadmap`, each entry says what is not done).

Report what breaks in the repository's issues.
