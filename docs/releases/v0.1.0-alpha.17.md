The seventeenth alpha of Sunset: security hardening & isolation across the whole app (App-Sandboxed zero-network XPC
services for the credential vault and terminal image decoding, mandatory expiring signed release indexes, MDM managed
preferences, SIEM audit log, CycloneDX SBOM + SLSA build provenance), Markdown `<details>`/`<summary>` & table `<br>`
support, and Reveal in Finder & Share actions for external Markdown tabs. Expect rough edges, and settings or saved
state that a later build may not read.

**What changed since alpha.16.**
- **App-Sandboxed, zero-network XPC isolation (`SunsetVaultService.xpc` & `SunsetImageDecoder.xpc`).**
  - Unlocked vault master keys and `Seal(.vaultRecord)` encryption/decryption now live inside an embedded App-Sandboxed,
    zero-network XPC service (`studio.aemi.sunset.vault`) so Sunset's main process never holds raw vault keys in memory.
  - Untrusted terminal Kitty PNG decoding runs inside an embedded App-Sandboxed, zero-network XPC service
    (`studio.aemi.sunset.imagedecoder`) with strict overflow-safe dimension checks and a 5 s timeout.
- **Hardened updates, extensions, pasteboard & governance.**
  - Signed `release-index.json` + `.sig` is now mandatory for builds ≥ 829 with an explicit 45-day expiry window
    (`issuedAt`/`expiresAt`) and tag/build validation against freeze and downgrade attacks.
  - Arbitrary-host `.xpi` page-link interception is closed: Firefox `.xpi` installs are restricted strictly to HTTPS on
    `addons.mozilla.org` with redirect verification, while `.crx` packages continue verifying CRX3 signatures.
  - `PasteboardImage` now checks declared header dimensions against the 16M-pixel limit before decoding.
  - Added enterprise MDM `ManagedPolicy` (`AllowExtensions`, `AllowCertificateExceptions`, `RequireHardenedWeb`,
    `RequireHTTPSUpgrade`, `AllowSafeDownloadAutoOpen`, `MaxVaultLockMinutes`, `RequireAutomaticUpdates`), bounded
    `0600` JSONL `SecurityAuditLog` for SIEM export, updated `docs/design/0006-threat-model.md`, and published
    `docs/design/0008-hardening-and-key-custody.md`.
  - Releases now include a CycloneDX 1.5 SBOM (`Sunset-0.1.0-alpha.17.sbom.cdx.json`) naming every SwiftPM dependency
    plus the exact Sunset WebKit base commit and patch count, alongside GitHub SLSA Build Provenance attestations.
  - Added seeded adversarial fuzz suites for CRX3 packages, `.svault` backup containers, and the VT escape parser, plus
    cached shared `MetalCompositor` pipelines per device and automatic Low Power Mode sky-shader pause.
- **Documents & Markdown.**
  - Upgraded `AemiMarkdown` (`b32d540`) and `TerminalKit` (`ac1e906`) for safe HTML `<br>` line breaks in tables and
    collapsible `<details>`/`<summary>` cards across both the native viewer and Quick Look extensions.
  - Added **Reveal in Finder** and **Share…** to the tab context menu for external Markdown/text documents opened from
    disk.

**Two variants of one app.**
- **Sunset** (`Sunset-v0.1.0-alpha.17-…`): pages on the system's WebKit, the one Safari uses.
- **Sunset with its own WebKit** (`Sunset-WebKit-v0.1.0-alpha.17-…`): the same app with WebKit's main branch at
  `944f9ff672` and 37 patches of ours. Switch between them in Settings › General › Updates › Web engine.

**Install.** Unzip, move the app to Applications, open it. Both are signed with a Developer ID and notarised by Apple.
They need macOS 26 or later and a Mac with Apple silicon.

**Check the download.** `shasum -a 256 -c NAME.zip.sha256` in the folder holding both files. Verify SLSA provenance with
`gh attestation verify NAME.zip --owner g-cqd`.

**Not in it yet.** Linux; Intel Macs; terminal scrollback search; restoring terminal screens across quit; Sixel and
iTerm2's images, kitty's animations; syncing the vault between Macs, KDBX / 1PUX / OTP-app imports; protected video on
some sites; several pieces of the roadmap (`docs/roadmap`, each entry says what is not done).

Report what breaks in the repository's issues.
