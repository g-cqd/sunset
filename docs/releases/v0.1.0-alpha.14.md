The fourteenth alpha of Sunset: a small one, about trusting what an update says. Expect rough edges, and settings or saved
state that a later build may not read.

**What changed since alpha.13.**
- **The update window checks release notes against the release's signature.** Notes are shown only as the signed index
  names them. A release from alpha.13 on whose notes do not match, or that has lost its index, has its notes withheld,
  with a word saying so. Releases from before signed indexes are marked as such.
- **Updates now come as the part that changed.** From alpha.13, Sunset fetches only the bytes its build needs from one
  update file per variant (a few megabytes rather than the whole app), and falls back to the whole app when it cannot.
- **Checked across an engine switch:** a vault and Sunset's own sealed data (tabs, favorites, settings) open the same on
  either web engine, in both directions.

**A correction to alpha.13's note.** Sunset WebKit (the separate app, up to alpha.12) already kept its tabs, favorites,
vault and settings in Sunset's own place: Sunset finds them. Only its website data (logins, cookies) stays with Sunset
WebKit and is not carried over.

**Two variants of one app.**
- **Sunset** (`Sunset-v0.1.0-alpha.14-…`): pages on the system's WebKit, the one Safari uses.
- **Sunset with its own WebKit** (`Sunset-WebKit-v0.1.0-alpha.14-…`): the same app with WebKit's main branch at 944f9ff672
  and 37 patches of ours. Switch between them in Settings › General › Updates › Web engine.

**Install.** Unzip, move the app to Applications, open it. Both are signed with a Developer ID and notarised by Apple. They
need macOS 26 or later and a Mac with Apple silicon.

**Check the download.** `shasum -a 256 -c NAME.zip.sha256` in the folder holding both files.

**Known.** Setting up Passwords with Touch ID on can close the window that shows the recovery code a few seconds after it
appears: copy the code at once, or set up without Touch ID. Being fixed.

**Not in it yet.** Linux; Intel Macs; Sixel and iTerm2's images, kitty's animations; syncing the vault between Macs,
importing from other password managers; protected video on some sites (CNN); several pieces of the roadmap
(`docs/roadmap`, each entry says what is not done).

Report what breaks in the repository's issues.
