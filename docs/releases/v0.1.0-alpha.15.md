The fifteenth alpha of Sunset: lazy restoration and manual unloading of tabs, vault import and export (CSV and Bitwarden JSON),
Markdown and Quick Look additions, and context-menu ink fixes. Expect rough edges, and settings or saved state that a later
build may not read.

**What changed since alpha.14.**
- **Tabs restore unloaded, and can be unloaded by hand.** Favorites, pinned tabs, and restored window tabs come back listed
  and wait unloaded until shown, named and searchable in the command bar from their saved data. Documents, idle terminals,
  and web pages can be unloaded by hand (including the tab on screen, which steps back to the previous tab; pages unload in
  place while keeping their address and history). Split favorites expose the full entry menu on each part.
- **Passwords: import and export.** The Passwords section's "…" menu adds **Import Logins…** (CSV from Apple Passwords,
  Chrome, Edge, Brave, Firefox, Bitwarden, 1Password, and LastPass, plus Bitwarden's unencrypted JSON export with logins,
  secure notes, cards, identities, folders, and custom fields) and **Export Logins to CSV…** (guarded by a warning, owner
  check, and a 0600 file). Duplicate detection and a detailed skip report are shown before anything is added.
- **Markdown, Quick Look, and surface alignment.** Added Markdown settings, Quick Look extensions, tab/folder settings, and
  aligned popover and preview surfaces.
- **Context menus keep the menu's own ink.** Every context menu now renders symbols with primary menu ink instead of blue
  accent tint.
- **Stability and updates.** Fixed a crash when a page outside any window focused a sign-in field, hid forged or unverified
  release titles behind "Unverified release (build N)", and fixed CI compilation against the macOS 26.5 SDK.

**Two variants of one app.**
- **Sunset** (`Sunset-v0.1.0-alpha.15-…`): pages on the system's WebKit, the one Safari uses.
- **Sunset with its own WebKit** (`Sunset-WebKit-v0.1.0-alpha.15-…`): the same app with WebKit's main branch at 944f9ff672
  and 37 patches of ours. Switch between them in Settings › General › Updates › Web engine.

**Install.** Unzip, move the app to Applications, open it. Both are signed with a Developer ID and notarised by Apple. They
need macOS 26 or later and a Mac with Apple silicon.

**Check the download.** `shasum -a 256 -c NAME.zip.sha256` in the folder holding both files.

**Known.** Setting up Passwords with Touch ID on can close the window that shows the recovery code a few seconds after it
appears: copy the code at once, or set up without Touch ID. Being fixed.

**Not in it yet.** Linux; Intel Macs; Sixel and iTerm2's images, kitty's animations; syncing the vault between Macs,
encrypted `.sunsetvault` backups, KDBX / 1PUX / OTP-app imports; protected video on some sites (CNN); several pieces of the
roadmap (`docs/roadmap`, each entry says what is not done).

Report what breaks in the repository's issues.
