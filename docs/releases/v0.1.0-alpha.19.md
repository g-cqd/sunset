The nineteenth alpha of Sunset: one table of commands behind the menus, the command bar, editable shortcuts, Shortcuts
and Spotlight; the `sunset` tool and an MCP server to let your scripts and agents work with Sunset, each session approved
by you; Settings reorganized by kind, with each feature's settings in a section of its own; pages in a scheme of their
own; and fixes for files that no longer opened and for Restart to Update. Expect rough edges, and settings or saved
state that a later build may not read.

**What changed since alpha.18.**
- **Commands.**
  - **One table of commands**: the menus are made from it, so a command has one title and one shortcut everywhere.
  - **Shortcuts as settings**: Settings › General › Keyboard shortcuts records a shortcut when you press it (one taken
    from another command moves); the configuration file's `keys` section sets them too ("cmd+shift+d", "" for none).
  - **The command bar** offers every menu command with its menu and shortcut, those whose title matches first, then
    those you use most, and learns the command a query ran: typed again, it is the first row.
  - **Shortcuts, Spotlight and Siri** can run any menu command ("Run Sunset Command").
- **Control from outside** (Settings › General › Control from outside, off by default).
  - The `sunset` tool, inside the app (`Sunset.app/Contents/Helpers/sunset`, linked in `~/.local/bin` from Settings):
    `sunset list`, `read`, `type`, `wait`, `run`, `commands`, over a socket only your user can open.
  - `sunset mcp`: an MCP server whose tools are those requests, for an AI agent.
  - Each session (a terminal's shell, or the app that started the tool) is approved by you once; Don't Allow is the
    default. Typing into terminals is a switch of its own, off by default. A pane being driven shows a mark on its tab;
    clicking it stops the tool for that pane.
- **Settings by kind.** General, Look and feel, Windows and tabs, Privacy and storage, then Terminal, Web, Documents and
  Passwords, each shown while its feature is on. The terminal's colors, programs and padding are under Terminal; web
  history, site data and protection under Web; the vault under Passwords.
- **Page appearance** (Web › Pages): pages in Sunset's scheme, the system's, light or dark, whatever Sunset's own.
- **Fixes.**
  - Settings, Help and Passwords follow Sunset's scheme: in light they are drawn light, not on the terminal's dark
    background.
  - Files (Markdown, text) open again from Finder, Open With, ⌘O and the command bar when the window in front shows no
    tab of Today, only Favorites and Pinned tabs; before, they waited for a window that never came.
  - Restart to Update no longer hangs when Sunset asks before quitting; a quit cancelled there no longer restarts
    Sunset at the next quit.
  - Favorites make room for a dragged tab as Today's tabs do, with no line in their gaps.

**Two variants of one app.**
- **Sunset** (`Sunset-v0.1.0-alpha.19-…`): pages on the system's WebKit, the one Safari uses.
- **Sunset with its own WebKit** (`Sunset-WebKit-v0.1.0-alpha.19-…`): the same app with WebKit's main branch at
  `c308255c50` and 37 patches of ours. Switch between them in Settings › General › Updates › Web engine.

**Install.** Unzip, move the app to Applications, open it. Both are signed with a Developer ID and notarised by Apple.
They need macOS 26 or later and a Mac with Apple silicon.

**Check the download.** `shasum -a 256 -c NAME.zip.sha256` in the folder holding both files.

**Not in it yet.** Linux; Intel Macs; light and dark values for each color setting; syncing the vault between Macs;
KDBX / 1PUX imports; protected video on some sites.

Report what breaks in the repository's issues.
