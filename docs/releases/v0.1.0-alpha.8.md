The eighth alpha of Sunset, in two builds. Expect rough edges, and settings or saved state that a later build may not read.

**Two builds.**
- **Sunset** (`Sunset-v0.1.0-alpha.8-…`): pages run on the system's WebKit, the one Safari uses, and get its security updates
  with macOS. Most people want this one.
- **Sunset WebKit** (`Sunset-WebKit-v0.1.0-alpha.8-…`, experimental): the same app with its own WebKit inside, built from
  WebKit's main branch at 944f9ff672 with 36 patches of ours. It gets **no WebKit security fixes from macOS updates**, only
  from a later Sunset WebKit; it says when its engine is eight weeks old. It is a separate app (`studio.aemi.sunset.webkit`)
  with its own settings.

**What changed since alpha.7.**
- **New tabs.** ⇧⌘T opens the command bar with the kinds of tab that are on: a terminal, a web page, a document. Typing
  narrows them.
- **The command bar** also goes to Sunset's own places: Settings, the Library, Documents, History, Downloads, Help.
- **Split tabs.** Their menu closes one pane; holding Option offers closing all of them.
- **The Library.** Swiping back the way you came returns to the tabs.
- **The sidebar.** Its dividing lines show only when something is under them.
- **An empty window** says what ⌘T does when terminals are off.
- **The welcome.** No dark band under its buttons.

**Install.** Unzip, move the app to Applications, open it. Both are signed with a Developer ID and notarised by Apple, so
they open without a warning. They need macOS 26 or later and a Mac with Apple silicon.

**Check the download.** `shasum -a 256 -c NAME.zip.sha256` in the folder holding both files.

**Not in it yet.** Linux; Intel Macs; updates (download the next build by hand); Sunset's own password manager (begun, not
shown); sharing data between the two builds; several pieces of the roadmap (`docs/roadmap`, each entry says what is not
done).

Report what breaks in the repository's issues.
