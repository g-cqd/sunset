The eleventh alpha of Sunset, in two builds, a day after alpha.10: fixes to it. Expect rough edges, and settings or saved
state that a later build may not read.

**Two builds.**
- **Sunset** (`Sunset-v0.1.0-alpha.11-…`): pages run on the system's WebKit, the one Safari uses, and get its security
  updates with macOS. Most people want this one.
- **Sunset WebKit** (`Sunset-WebKit-v0.1.0-alpha.11-…`, experimental): the same app with its own WebKit inside, built from
  WebKit's main branch at 944f9ff672 with 36 patches of ours. It gets **no WebKit security fixes from macOS updates**, only
  from a later Sunset WebKit; it says when its engine is eight weeks old.

**What changed since alpha.10.**
- **Passwords.**
  - Unlocking with Touch ID asks once (it asked twice).
  - Any field of an entry can be made secret, or shown plainly; a secret has an eye to show it, in a monospaced face; while
    an entry is edited, a field's name is edited in place and its kind can be changed.
  - A field is copied with its button, not by a click anywhere on it.
- **A click on a menu or a picker** (in Settings, in Passwords) no longer opens a second menu half a second later.
- **The tab shown** stands apart from the others in the sidebar, in a window at the back too, and changes more softly.

**Install.** Unzip, move the app to Applications, open it. Both are signed with a Developer ID and notarised by Apple, so
they open without a warning. They need macOS 26 or later and a Mac with Apple silicon.

**Check the download.** `shasum -a 256 -c NAME.zip.sha256` in the folder holding both files.

**Known.** Setting up Passwords with Touch ID on can close the window that shows the recovery code a few seconds after it
appears: copy the code at once, or set up without Touch ID (it cannot be turned on later yet). Being fixed.

**Not in it yet.** Linux; Intel Macs; updates (download the next build by hand); Sixel and iTerm2's images, kitty's
animations and Unicode placeholders; syncing the vault between Macs, importing from other password managers; protected
video on some sites (CNN); several pieces of the roadmap (`docs/roadmap`, each entry says what is not done).

Report what breaks in the repository's issues.
