The first build of Sunset for others to try: an alpha. Expect rough edges, and settings or saved state that a later build may not read.

**What it is.** A terminal emulator for macOS written in Swift: a platform-free parser and screen, a Metal renderer (with a CPU one to fall back on), kitty keyboard and graphics, OSC 8, 52 and 133, ligatures and colour emoji. Its window holds terminals, web pages, Markdown documents and folders as tabs, with a sidebar, Spaces and profiles.

**Install.** Unzip, move Sunset.app to Applications, open it. It is signed with a Developer ID and notarised by Apple, so it opens without a warning. It needs macOS 26 or later and a Mac with Apple silicon.

**Check the download.** `shasum -a 256 -c Sunset-v0.1.0-alpha.1-macos-arm64.zip.sha256` in the folder holding both files.

**Not in it yet.** Linux; updates (download the next build by hand); several pieces of the roadmap (`docs/roadmap`, each entry says what is not done).

Report what breaks in the repository's issues.
