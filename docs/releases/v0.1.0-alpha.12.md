The twelfth alpha of Sunset, in two builds, plus the WebKit engine as a downloadable component. Expect rough edges, and
settings or saved state that a later build may not read.

**Two builds (and the engine component).**
- **Sunset** (`Sunset-v0.1.0-alpha.12-…`): pages run on the system's WebKit, the one Safari uses, and get its security
  updates with macOS. You can also download Sunset's own WebKit engine from Settings › General › Updates, switch between
  the two, or delete it to free disk space. Most people want this build.
- **Sunset WebKit** (`Sunset-WebKit-v0.1.0-alpha.12-…`, experimental): the same app with its own WebKit inside, built from
  WebKit's main branch at 944f9ff672 with 37 patches of ours. It gets **no WebKit security fixes from macOS updates**, only
  from a later Sunset WebKit; it says when its engine is eight weeks old.
- **SunsetEngine** (`SunsetEngine-v0.1.0-alpha.12-…`): the notarised WebKit engine archive fetched by Sunset when you opt
  in to the component.

**What changed since alpha.11.**
- **Self-updating from GitHub releases.** Sunset now checks for updates, downloads incremental binary delta packages when
  available (or the full archive otherwise), verifies the code signature, notarisation and build order, and swaps itself in
  on quit or restart. Settings › General › Updates shows versions, automatic update toggles, and a redesigned update window
  with the release notes between versions. (This is the first build with the updater; the first live self-update will be
  from alpha.12 to alpha.13.)
- **WebKit security hardening & downloadable engine.** Sunset WebKit no longer needs the `allow-dyld-environment-variables`
  hardened-runtime exception or a relaunch at startup: its executables carry the framework path directly, and its helper
  processes run under Sunset's own XPC service names. The native Sunset app ships those services too and can download,
  toggle, update and delete the engine component.
- **Passwords.**
  - Edits save automatically (shortly after changes, on losing focus, on leaving the page, and before any vault lock);
    Cancel restores the entry as it was when editing began.
  - Auto-lock settings under Settings › Privacy and security › Passwords: lock after a chosen idle duration, on leaving the
    vault tab, or when its window loses focus.
  - Editing a field's name, kind and secrecy now happens in a dedicated sheet with a confirmation before any lossy kind
    change.
  - Fixed Passwords missing from a second window's Library when the feature is enabled.
- **Appearance & welcome.**
  - Settings › Appearance › App icon now shows icon previews instead of a name dropdown, with an **Auto** default that
    follows the time of day (Dawn, Sunset, Twilight, Dusk).
  - The welcome opening animation and sky adapt to the time of day using each icon's preset.
- **Tabs, menus & media.**
  - Tab, folder and favorite context menus add Duplicate, Copy Address (multi-select and folders included) and Share, with
    monochrome icons across the menu.
  - A docked web inspector now survives switching tabs.
  - Favorites, pinned tabs and sleeping tabs are not tinted until loaded.
  - Now Playing cards disappear when media ends, can be dismissed, seek ±10 seconds on seekable media, rest without a
    leading marquee fade, and carry a subtle shadow; the sidebar's last row clears the bottom fade.
  - The Downloads button turns into a checkmark for three seconds when a download finishes.
- **Terminal.**
  - Kitty Unicode image placeholders are now drawn.
  - Unused hyperlink addresses are compacted when the link table fills.

**Install.** Unzip, move the app to Applications, open it. Both are signed with a Developer ID and notarised by Apple, so
they open without a warning. They need macOS 26 or later and a Mac with Apple silicon.

**Check the download.** `shasum -a 256 -c NAME.zip.sha256` in the folder holding both files.

**Known.** Setting up Passwords with Touch ID on can close the window that shows the recovery code a few seconds after it
appears: copy the code at once, or set up without Touch ID (it cannot be turned on later yet). Being fixed.

**Not in it yet.** Linux; Intel Macs; Sixel and iTerm2's images, kitty's animations; syncing the vault between Macs,
importing from other password managers; protected video on some sites (CNN); several pieces of the roadmap
(`docs/roadmap`, each entry says what is not done).

Report what breaks in the repository's issues.
