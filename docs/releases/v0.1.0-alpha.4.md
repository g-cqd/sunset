The fourth alpha of Sunset, and the first in two builds. Expect rough edges, and settings or saved state that a later build may
not read.

**Two builds.**
- **Sunset** (`Sunset-v0.1.0-alpha.4-…`): pages run on the system's WebKit, the one Safari uses, and get its security updates
  with macOS. Most people want this one.
- **Sunset WebKit** (`Sunset-WebKit-v0.1.0-alpha.4-…`, experimental): the same app with its own WebKit inside, built from
  WebKit's main branch (aa9b09cf67) with 18 patches of ours that make browser extensions written for Firefox and Chrome
  work, uBlock Origin among them: blocking, redirects to its stand-in scripts, its dashboard. Read before using it:
  - it gets **no WebKit security fixes from macOS updates**, only from a later Sunset WebKit;
  - to load its own WebKit it runs with a loader exception (`allow-dyld-environment-variables`) that the plain build does
    not have, and without the private entitlements Safari's WebKit has for its sandbox; its threat model is not written yet;
  - it is a separate app (`studio.aemi.sunset.webkit`) with its own settings, beside Sunset if both are installed.

**What changed since alpha.3.**
- Browser extensions: File ▸ Install Extension…, or Add to Sunset on the Chrome Web Store's and Firefox Add-ons' pages. A
  prompt says what an extension may do; Settings ▸ Web ▸ Extensions lists them per profile. Each one's button sits beside the
  sidebar's pin with its badge and popup; the ones that do not fit are behind the puzzle piece.
- An extension's popup can open tabs and windows, and its options page opens in a tab.
- An extension's pages open in a tab, keep one address across launches, and the address field shows the extension's name.
- Extensions that block with `webRequest` (uBlock Origin from Firefox Add-ons) block only in Sunset WebKit; on the
  system's WebKit they load but do not block.
- Videos are composited as Safari does them.

**Install.** Unzip, move the app to Applications, open it. Both are signed with a Developer ID and notarised by Apple, so
they open without a warning. They need macOS 26 or later and a Mac with Apple silicon.

**Check the download.** `shasum -a 256 -c NAME.zip.sha256` in the folder holding both files.

**Not in it yet.** Linux; Intel Macs; updates (download the next build by hand); in Sunset WebKit, request header changes
from extensions and events for pages loaded from the cache; uBlock Origin's privacy switches (pre-fetching, hyperlink
auditing) show but change nothing; several pieces of the roadmap (`docs/roadmap`, each entry says what is not done).

Report what breaks in the repository's issues.
