The seventh alpha of Sunset, in two builds. Expect rough edges, and settings or saved state that a later build may not read.

**Two builds.**
- **Sunset** (`Sunset-v0.1.0-alpha.7-…`): pages run on the system's WebKit, the one Safari uses, and get its security updates
  with macOS. Most people want this one.
- **Sunset WebKit** (`Sunset-WebKit-v0.1.0-alpha.7-…`, experimental): the same app with its own WebKit inside, built from
  WebKit's main branch at 944f9ff672 with 36 patches of ours. Read before using it:
  - it gets **no WebKit security fixes from macOS updates**, only from a later Sunset WebKit; it now says when its engine is
    eight weeks old, and About names the engine and its date;
  - it refuses to start with a WebKit that is not its own (another release's frameworks swapped in);
  - extensions that block requests (uBlock Origin from Firefox) can change a page's security headers there: the install
    prompt says so;
  - it is a separate app (`studio.aemi.sunset.webkit`) with its own settings, beside Sunset if both are installed.

**What changed since alpha.6.**
- **Extensions.**
  - Installing from the Chrome Web Store or Firefox Add-ons works whatever browser Sunset is set to show; it needed Chrome
    before.
  - Extensions work in favorite and pinned tabs.
  - In a terminal or a document, their buttons are grey and faded.
  - One install prompt per press, drawn in one frame.
- **Your data at rest.** What sites keep (their databases, local storage, service workers) is sealed when Sunset quits and
  opened when it starts, as cookies already were. A copy or a backup of your Library taken while Sunset is closed holds none of
  it readable. Caches stay out of backups.
- **Tabs.**
  - Favorites can be split: drag one onto a tab or a pane, or select favorites with tabs and choose a layout.
  - Pinned tabs stay whole.
  - Dragging shows only where the tab would land, in white, and the tab rows move apart to make room.
  - The trackpad ticks as it snaps.
- **The welcome.** The sun sets before the window comes into focus; the window sits at the screen's optical centre. There
  may be a way to watch it again.
- **The terminal.** Control characters written as text (U+0080 to U+009F) are dropped unless Settings turns them on: what
  escapes its output for a terminal rarely escapes these.
- **Importing.** Import from Another Browser is in the command bar; Firefox containers can become profiles.
- **Sites that check the browser.** Shown as Chrome or Firefox, Sunset no longer offers native HLS video, as they do not.

**Install.** Unzip, move the app to Applications, open it. Both are signed with a Developer ID and notarised by Apple, so
they open without a warning. They need macOS 26 or later and a Mac with Apple silicon.

**Check the download.** `shasum -a 256 -c NAME.zip.sha256` in the folder holding both files.

**Not in it yet.** Linux; Intel Macs; updates (download the next build by hand); Sunset's own password manager (begun, not
shown); sharing data between the two builds; several pieces of the roadmap (`docs/roadmap`, each entry says what is not
done).

Report what breaks in the repository's issues.
