# 0011 — The terminal is called Sunset

## Decision

The terminal is **Sunset** (owner, 2026-11-05). The repository directory is `sunset`. It completes ADR-0001, whose name clause ("undecided") it supersedes. `Aemi*` names remain for dependencies only.

## Consequences

- Product, module and bundle names derive from `Sunset`; the placeholder `terminal-tbd` is gone from the tree (historical snapshots under `docs/research` and the diary keep the older wording on purpose).
- A GitHub Swift search for `sunset` found only unrelated projects (a sunrise/sunset calculator among them); trademark, App Store and bundle-identifier availability were **not** checked.
