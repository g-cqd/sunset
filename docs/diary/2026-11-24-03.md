# 2026-11-24 — 03: Popover/preview surface alignment, Markdown rendering & Quick Look extensions, tab/folder settings

## Summary of claims, probes and verdicts

| Claim | Probe | Verdict |
|---|---|---|
| Site settings popover was too dark because it stacked an opaque `windowBackgroundColor` with a 0.75 `BarTint` black wash, while previews had no shade at all | Removed the duplicate `.background` on `SiteSettingsPopover`, lowered `Design.Fill.popoverShade` from `0.75` to `0.35`, and aligned `PopoverSurfaceModifier` and shaded `SurfaceModifier` (`TabPreviewCard`, `FolderPreviewCard`) onto the same `SurfaceFill` + `popoverShade` middle ground | builds; tests pass |
| `NativeRichText.monospacedSpace` crashed MarkdownLook in CoreText `TAttributes::ApplyFont` with nil dictionary object | Measured monospaced NBSP width directly with `CTFontGetGlyphsForCharacters` + `CTFontGetAdvancesForGlyphs` in `AemiMarkdown` (`653e200`, local commit); tested across all font faces (`NativeMonospacedSpaceTests`) | holds (154/154 tests pass in `AemiMarkdown`) |
| Headings mixing prose and inline code spans wrapped narrowly and overlapped following content | Reproduced red first in `NativeMixedHeadingTests`: `BalancedLayout` balanced plain-text `CTTypesetter` (ignoring wider code pills) and re-ran `balancedWidth` on already-shrunk `bounds.width` in `placeSubviews`. Switched `BalancedLayout` to balance against the SwiftUI subview's `sizeThatFits` and reuse the cached width in `placeSubviews` | holds (red -> green) |
| Open tabs inside collapsed Favorites folders should stay visible by default, toggleable | Added `sidebar.showOpenInCollapsedFolders` (default `true`), updated `Favorites.rows(selected:showOpenInCollapsed:)` and all sidebar/selection/gap callers; red-first `FavoritesRowsTests` | holds |
| Users need a toggle to switch immediately to a newly opened tab or peek window | Added `web.focusOpenedTabOrPeek` (default `false`), wired into `WebOpening`, `DocumentWiring`, `AppActions+Pages`, `TabsModel.newTab(_:show:)`, and `PopupWindowStore.attach` | holds |
| Markdown rendering settings and Quick Look extensions belong inside Sunset (retiring MarkdownLook.app) | Added all Markdown rendering settings to `Configuration.Documents` and `SettingsOption.documents` (wired live into `OpenDocuments`/`DocumentLook` and mirrored to `studio.aemi.sunset.quicklook`). Added `SunsetMarkdownPreview.appex` and `SunsetMarkdownThumbnail.appex` targets to `project.yml` and a `QuickLookMarkdownRow` toggle + System Settings button in Settings › General › Documents | holds; Release `Sunset.app` embeds both `.appex` bundles and verifies with `codesign --verify --deep --strict` |
