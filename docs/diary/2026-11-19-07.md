| t48 D needs a memory-hard KDF for the recovery code | `StorageKey`, `RecoveryCode` read | No: the code is the 32-byte key itself in Crockford base32 with a 2-character check, nothing typed by a person. Argon2 has no use there; its uses are a vault's master password and passphrase-sealed backups |
| t48 C costs the database's own work | `SealedTable` read | History's pruning is one `DELETE … WHERE sort < ?` on the clear time. Every row is opened at load already (`SealedRows`), so pruning moves to memory at no extra reading |

| WebKit's stores can be put anywhere | `wk-store-paths.swift`: `_WKWebsiteDataStoreConfiguration`'s properties | `initWithIdentifier:` and every store's path: network cache, cookie file, IndexedDB, web storage, service workers, HSTS, alternative services, resource load statistics, media keys, cache storage, general storage; `WKWebsiteDataStore _initWithConfiguration:` present |
| FileVault already seals the disk | `fdesetup status`, `diskutil apfs list` | "FileVault is On", the data volume "FileVault: Yes (Unlocked)" |

Cheap |

Sunset sets none of the last four |
