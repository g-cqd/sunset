# 2026-11-17

## An entry between the Favorites and the Pinned grid, and the menus (ADR-0054)

The owner's report, on trying the grid: the menus did not hold everything about pinning and favourites, and a
favourite could not be pinned.

Red first: `TabsPinnedFavoritesTests` did not build (no `pin(entry:)`, `favorite(pinned:)`, `canPin(_:)`, `pin(_:)`);
then "a pinned entry dropped among the Favorites goes there" failed (the entry stayed in the grid); then "resetting an
entry in which something runs asks first" failed (it was stopped without a question).

| Claim | Probe | Verdict |
|---|---|---|
| A favourite can be pinned | The owner tried; the code read | **Refuted**: nothing did it, in any menu or by any drag |
| A single tab's row dragged onto the grid is pinned (ADR-0050) | The code read: `draggedSelection` is nil unless several rows are marked | **Refuted**: only a marked selection was pinned. A test now drags one row |
| A favourite pinned is the same entry, still running | Tests: its id, name, icon, command, its content not stopped, still shown and drawn where it was | Holds |
| The menus hold it all | Each context menu opened through accessibility (`AXShowMenu`) and its items read | A tab: Rename, Change Icon…, Pin, Add to Favorites, New Folder with This Tab, Close Tab, Close Other Tabs. A favourite: Show, Pin, Remove from Favorites, Rename, Change Icon…, Edit Command…, Reset to Home, Set Home to Current, Unload, Delete. A tile: Show, Unpin, Move to Favorites, Rename, Change Icon…, Edit Command…, Reset to Where It Was Pinned, Pin Where It Is Now, Unload, Delete |
| Pin in a favourite's context menu pins it | The item pressed in the open menu | The row gone from the Favorites, a tile in the grid |
| The menu bar does both ways | Add to Favorites, Pin, Add to or Remove (a favourite again), Pin, Unpin | Each as said; unpinned, it is a tab after the others |

Learnt about the probe: a context menu can be opened in a test copy with `axdrive press … --action AXShowMenu`; the call
does not return while the menu is open (it reports a timeout), the items are then in the tree, and Escape closes it.
