## Sunset started with no window (ADR-0039)

Found while probing M-f; fixed first, on its own. No suite covers the app target: the red is what the app did.

| Claim | Probe | Verdict |
|---|---|---|
| The installed release build opens a window | `axdrive launch`, 8 s and 20 s | **Refuted**: "no window within the timeout"; the process runs, idle |
| The document types of M-f are the cause | The M-d build, which has none | **Refuted**: no window either |
| The system's saved state is the cause | AppKit's log; the same build with `-ApplePersistenceIgnoreState YES`; a copy signed ad hoc | **Confirmed**: `hasPersistentStateToRestore=1` and no window; with the flag `=0` and a window; the ad hoc copy, which has its own record, a window. The record: `windows.plist`, no window in it, written by a test copy ended by a signal |
| In that state New Window opens one | File > New Window | **Refuted**: nothing; only a window sets `openTerminalWindow` |
| With `ignoreSavedState()` a window opens on that record | The debug app, the record still there | A window, at the remembered frame; `hasPersistentStateToRestore=0` |
| `.restorationBehavior(.disabled)` costs nothing | The first window's frame | **Refuted**: 820x520 in the middle instead of the remembered 1684x985; removed |
| With the menus saying how, New Window works from nothing | The fix taken out for one build, the record there | No window at the start, one after New Window |
| `isRestorable = false` keeps titles out of the record | Two windows, 15 s, then a kill; before and after the change | **Not shown**: neither build wrote anything (the screen was locked throughout) |

Learnt about the probe: with the screen locked the accessibility tree has menus and no windows; `axdrive windows` and

## Markdown M-f: opening (ADR-0040)

Red first, 2026-11-16: `FileDropTests`, `TypedPathTests`, `TabsOpenFilesTests` (SunsetShellTests) and `AppBundleTests`
(SunsetCoreTests) did not build: no `FileDrop`, no `TypedPath`, no `TabsModel.open(files:)`, no document types in
`App/Info.plist`.

| Claim | Probe | Verdict |
|---|---|---|
| A dropped path is typed so that the shell reads nothing of it | `FileDropTests`: 14 names with `$ ; & \| * ? ( ) < > ! # ~ " \` and a backquote | Each in single quotes; a quote inside as `'\''` |
| A name with a control character is never typed | 9 names: ETX, LF, CR, ESC `[201~`, DEL, NUL, TAB, CSI (C1), U+2028 | Nothing typed, nor the names dropped with it |
| Sunset can open the three types and is never their default | `AppBundleTests` on `App/Info.plist` | Role Editor, rank Alternate, for all three |
| A Sunset with the types still opens its window | `axdrive launch`, direct | A window (after ADR-0039) |
| A file opened with Sunset opens in a tab | `axdrive launch --open notes.md` (new: `/usr/bin/open -n -g -a` with the test's environment) | **Refuted at first**: a blank window. Trace: the first window attached, then `willClose`, then `application(_:open:)` with no window registered; SwiftUI had made a second window for the file and closed the first |
| `handlesExternalEvents(matching: [])` stops that | The same launch | No window at all: AppKit makes no first window for a Sunset started on a file |
| `open(files:)` opening the window itself gives one window with the file | The same launch; then with a session of two tabs | `notes.md` alone in one window; with the session, its two tabs and `other.txt` after them, selected (picture read) |
| A running Sunset opens them in its window, and one it shows is shown | `open -g -a` with `other.txt` and `link.md`, a link to `notes.md` | `other.txt` added; `notes.md` selected, not opened twice |
| A typed path gives an Open row first | Edit > Command Bar, `/tmp/md-d/third.md`, Return | "Open third.md /tmp/md-d File" above the search (`md-bar-file-row.png`); Return opens it in a tab |

Not seen: a drop (none can be made in the background), the + menu's two items and the stored documents' rows in the bar
(the screen was locked: no element of a window is reachable through accessibility, only menus), Finder's Open With.

**A mistake of the probe, to know about.** `open -g -a .build/app/Sunset.app FILE` was run once after the test copy had
ended: it started a Sunset with no test environment, on the owner's configuration and session. It restored his three tabs,
added `other.txt`, wrote `session.sealed` at 09:13:44 and was killed. His running Sunset writes the session again at its
next change and at quit. From now on a file is only ever sent through `axdrive launch --open`, never through `open -a`.
