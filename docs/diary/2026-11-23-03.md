# 2026-11-23 — 03: Updates from GitHub, what a delta saves (roadmap 0122 step A; ADR-0122)

The owner (n135): Sunset updates itself and its components, with no third party, from GitHub only, incrementally.

| Claim | Probe | Verdict |
|---|---|---|
| GitHub's releases list is readable without an account | `curl` of `api.github.com/repos/g-cqd/sunset/releases` | holds: 200 |
| Release assets take ranges | `Range: bytes=0-99` on alpha.11's zip, redirects followed | holds: 206, `content-range: bytes 0-99/22582852` |
| `releases/latest` finds our releases | `gh release list` | refuted: all eleven are pre-releases, which `latest` leaves out; the list is read instead |
| Whole files changed are few between builds | alpha.10 and alpha.9 to alpha.11 (native), the unzipped apps' SHA-256 per file | refuted as a saving: 8 of 20 files change, but they are the executable (9.2 MB zipped) and `Assets.car` (13.1 MB zipped): 22.3 of 22.6 MB to fetch |
| Content-defined chunks save much | gear-hash chunks of 4 and 16 KiB, those of the new file not in the old, zlib | half: `Assets.car` 13.1 MB to 0.11 MB (1278 bytes differ); the executable 9.2 to 8.3–8.7 MB (addresses move everywhere) |
| A binary delta saves much | `zstd --patch-from` (a measure only; Sunset will not use it) | holds: the executable 2.8 MB from alpha.10, 3.3 MB from alpha.9; `Assets.car` 2 KB. alpha.10 to alpha.11 about 2.8 of 22.6 MB (12 %) |

So: deltas of our own per changed file (ADR-0122), from the last few builds, the full zip otherwise. A delta of bsdiff's kind
is to be measured against `zstd`'s figures when it exists (step C).

## Step C: our delta (`BinaryDelta`, `SunsetDeltaTool`)

| Claim | Probe | Verdict |
|---|---|---|

alpha.10 to alpha.11 as an update: about 1.2 MB of 22.6 MB.
