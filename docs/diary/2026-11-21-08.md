## Updating our WebKit fast (the owner: "update it fast and run the patching fast")

`Scripts/webkit.sh update [COMMIT]` takes WebKit's main (or COMMIT) in one go: a shallow fetch, the series applied three-way
with rerere in the same tree (so the build is incremental), a patch WebKit already has left out by name (it applies in
reverse: the grid backport, 0037, on any base after 327494@main), the build, then `test`. Only when all of that passes is
`Engine/WebKit/base` moved and the series exported again (ADR-0110). `test` runs the TestWebKitAPI suites the series is held
to and 453 layout tests in 155 s; a failure fails it unless `Engine/WebKit/known-failures` names it with its reason (the
localization tests, on a Mac whose languages are not English only). `Scripts/webkit.sh status` says where the tree is.
