# 2026-11-23 — 13: Reassessing the engine folder & incremental update format (ADR-0125)

The owner rejected `.SunsetEngine` beside the app and asked for an adversarial review of both the incremental update format
and the single-app strategy.

## Probes

| Claim | Probe | Verdict |
|---|---|---|
| GitHub release CDN honours `If-Range: <ETag>` | `curl -I -H "Range: bytes=1024-2047" -H 'If-Range: "wrong"'` against `release-assets.githubusercontent.com` on alpha.12 | **refuted**: returned `206 Partial Content`, ignoring `If-Range`. `If-Match: "wrong"` returned `412 Precondition Failed` |
| GitHub release CDN supports multi-range requests | `Range: bytes=0-99,200-299` | **refuted**: `501 Not Implemented` |
| Range past EOF works on small assets | `Range: bytes=0-65535` on a 114-byte `.sha256` | holds: `206`, `content-range: bytes 0-113/114` |
| Signed redirect URL expiry | `se=` query parameter on `release-assets.githubusercontent.com` | ~42 minutes; resumed downloads must re-resolve the GitHub URL on `403` |
| Why `Sunset-WebKit` deltas timed out at 10 min | byte comparison of `WebCore` (122.46 MB) before and after `codesign --timestamp` | only 18 bytes in the Mach-O header + 239 KB in `LC_CODE_SIGNATURE` at 122.21 MB differ; 99.8% is identical, yet `SuffixSort` sorted all 122 MB |
| Shared `WKWebsiteDataStore` survives switching Sunset WebKit → System WebKit | two Developer ID apps sharing bundle ID `studio.aemi.sunset.probe.ws` writing localStorage, cookies, IndexedDB via Sunset WebKit, reading via System WebKit and vice versa | System → Sunset: all three intact. Sunset → System: localStorage and cookies intact, **IndexedDB returned `null`** (back to Sunset WebKit: `"idb-val"` intact). Separate per-variant `WKWebsiteDataStore` IDs prevent silent IndexedDB loss on downgrade |

## Decision

ADR-0125 supersedes ADR-0124 and extends ADR-0122:
- Retire the external `SunsetEngine` folder and the separate `Sunset WebKit.app` identity: one `Sunset.app`
  (`studio.aemi.sunset`) with two complete notarized variants (System WebKit vs. Sunset's WebKit), switched via the
  updater. Separate `WKWebsiteDataStore` UUIDs per variant.
- Single range-addressed `.deltas` archive (`SSDLTA2`) per variant per release: capped at `K = 3` previous builds + the
  other variant at the same build, 65% size cutoff, one contiguous byte range per source build, `If-Match: <ETag>`,
  streaming progress.
- Signed release index (`release-index.json` + Ed25519 signature, main + backup public keys embedded in Sunset) binding
  every zip, `.deltas` TOC, and release notes before parsing or decompression.
- Hardening: bounded streaming LZMA (`compression_stream`), strict manifest/symlink validation, HTTPS GitHub host pinning,
  common-prefix/suffix skip in `BinaryDelta.make`, manifest-based verification in `SunsetDeltaTool`.

## Implementation & verification (ADR-0125)

| Claim | Probe | Verdict |
|---|---|---|
| Streaming LZMA enforces output cap against decompression bombs | `BoundedCompressionTests` (256 KiB input compressed to < 2 KiB, decompressed with 4 KiB cap) | holds: throws `outputLimitExceeded`; round-trip exact |
| Ed25519 signed release index verifies with main or backup key, rejects rogue/tampered | `ReleaseIndexTests` + live end-to-end sign on signing host (`openssl pkeyutl -rawin`) verified with Swift CryptoKit | holds: 64-byte signature, `isValidSignature == true` |
| Single `SSDLTA2` archive covers multiple sources via 1 contiguous range each, drops sources > 65%, rejects escaping symlinks, pins GitHub HTTPS hosts | `DeltaArchiveTests` (red first, then green; caught rangeOffset fixpoint bug and simplified to payload-relative offsets) | holds: all 39 `SunsetUpdateTests` pass |
| O(N) same-offset fast path speeds up re-signed `WebCore` (122 MB) | `SunsetDeltaTool make`/`apply` on 122.46 MB `WebCore` before/after `codesign --timestamp` | **1.42 s** (down from ~52–100 s!), 263 KB delta, applied in 0.45 s, byte-exact |
| Same-build variant switching via `SSDLTA2` between Native and WebKit `Sunset.app` (`studio.aemi.sunset`) | `SunsetDeltaTool archive` on built release apps (self-verified via manifest equality) | **Native → WebKit: 47 MB** (vs 97 MB full zip); **WebKit → Native: 17 KB** (vs 22 MB full zip); both bundles verify `codesign --deep --strict` with identical `studio.aemi.sunset` identifier |
| Per-variant `WKWebsiteDataStore` identifiers are deterministic and distinct | `VariantStoreTests` | holds |
| Full suite + quality + release builds | `swift test`, `.ci/swift-ci run quality`, `make-app.sh`, `make-webkit-app.sh` | 20/20 test runs passed, 0 warnings, clones 133, quality exit 0 |
