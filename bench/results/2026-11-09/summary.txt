How the scrolling regression was found: comparing these numbers with 2026-11-06 showed Sunset's scrolling slower than before; an interleaved bisect put it
on 4d24b1b (moved-rows map, +15-22 %); fixed in fd8157d, now faster than before it (30 / 20 / 42 ms against 33-34 / 23-24 / 48).

Caveats: one run of vtebench per terminal (Sunset's own A/B runs repeat within 1 ms); wall times move with load; vtebench and the flood measure
consuming output, not frame rate or input latency, which are not measured here; no energy figure.
