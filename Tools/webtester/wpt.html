web-platform-tests

The shared test suite Chromium, Firefox and WebKit each import and run (github.com/web-platform-tests/wpt, results at wpt.fyi). The folders below are the ones about what the tester covers, fetched by Scripts/web-tester.sh wpt and served from this server at their own paths.

Here, by hand in any browser: a test that needs nothing but the page runs; one that grants itself a permission or presses a key through testdriver cannot (that takes WebDriver), and says so. Tests whose name has manual are meant for a person. The official way, every test in Chrome, Firefox or Safari: ./wpt make-hosts-file | sudo tee -a /etc/hosts once, then ./wpt run --channel=nightly firefox mediacapture-streams (or chrome, safari after safaridriver --enable), from the checkout in .build/web-tester/wpt.
