# CI

Written 2026-11-05 from TerminalKit's and ask's setups; on GitHub since 2026-11-17.

- `.github/workflows/ci.yml` calls the family's pinned swift-ci workflow, configured by `action.json`: quality (swift-format, SwiftLint metrics, the shipped-library discipline) and the macOS release tests on every push, pull request and nightly. macOS only for now (the core is platform-free, a Linux leg comes with roadmap 0013).
- The quality step also runs the family's analyzers on `Sources`: deadwood (code nothing reaches), dolly (clones) and arcleak (retain cycles). What they reported on 2026-11-20 is accepted in `.ci/baselines/<tool>.json` (`.ci/swift-ci baseline` rewrites them): 144 clones, the same number `CloneRatchetTests` holds until roadmap work removes them (t92), and 13 declarations reached only from tests. A new finding fails the step.
- `.github/workflows/release.yml` publishes a tag `v*`: `Scripts/package-release.sh` builds the release app, signs it with the team's Developer ID, notarises it, zips it with its SHA-256, and `gh release create` attaches both, with `docs/releases/<tag>.md` as the note (a pre-release when the tag has a suffix). It needs seven repository secrets, listed at the top of the workflow (the certificate as a base64 .p12 and its password, the Developer ID profile, the team identifier, an App Store Connect API key with its identifier and issuer); none is in the repository. By hand (workflow_dispatch) it builds ad hoc, without the secrets, and keeps the zip as the run's artifact. The same script makes a release on the owner's Mac.
- Mutation testing is a command of `.ci/action.json` (`mutation`, litmus, pinned in swift-ci's tool lock), by hand on macOS for now (a nightly cadence follows once a baseline is committed), CI only (white paper §1): the pure models (`SunsetCore`, `SunsetPane`, `SunsetConfig`, `SunsetDocuments`) for two hours at most, in place. A survivor fails the run, except one accepted in `.ci/baselines/litmus.json` (none yet: the first run's result is the baseline to commit by hand). Sunset uses litmus and swift-ci for it, and no other tool; the script and workflow of the earlier tool are gone.
- Benchmarks are not compared in CI yet (`Benchmarks/` has no thresholds for the parser and screen); TerminalKit's `benchmarks` job is the model when they do.
- The workflow pins swift-ci at a commit; its tool lock (SwiftLint 0.65.1, SwiftFormat 0.64.7, deadwood 0.16.0, dolly 0.14.4, arcleak 0.17.5, litmus 0.4.1 for local mutation runs) comes with it. Bumped 2026-11-24 to `7d19957`.
